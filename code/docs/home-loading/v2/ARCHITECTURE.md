# Loading Portal V2 — isolated Lab release
## Shared composition
`LoadingPortalV2` renders a single centered, uniform cover plane containing the approved static reference, Drawer paths, DOM counter, and mechanical sprites. All read `portal-door-geometry.json` through the canonical catalog. The selected variant is decoded in one loader, background first, and previous complete art remains until the replacement is ready. Variant freezes during opening; CSS cover still adapts the same plane. Core is a child of the left leaf. The reference stays unchanged until mechanical activation.
The host provides confirmed progress and readiness. The integer counter floors its input and clamps to 99 until readiness AND assets. WAAPI handles the 1800ms opening, pausing offscreen/hidden tab; reduced-motion skips travel. The shared component never calls Supabase or simulates readiness. The lab alone has explicit simulation, speed/intensity, layer modes, reset, replay and failure controls.
