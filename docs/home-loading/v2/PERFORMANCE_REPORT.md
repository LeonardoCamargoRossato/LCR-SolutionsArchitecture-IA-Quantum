# Performance validation protocol
Status: measurement workflow implemented; numbers not yet certified. Compare actual production V1 baseline e092227, V2 and V2 bypass on equivalent headless Chromium, desktop/mobile normal and mobile with 4x CPU/1.5Mbps/100ms, cold and warm. The CI artifact records FCP, LCP, CLS, long tasks, real boot marks, time to Home visible/interactive, mechanical duration, request paths/bytes, CDP TaskDuration/JS heap and observed frame P95. These are controlled browser proxies, not guarantees for all physical devices. Compare actual results before asserting performance gains. V1 frames remain recoverable; V2 requests only the selected WebP reference and three mechanical sprites. No animation loop in the coordinator; real task events update progress.
