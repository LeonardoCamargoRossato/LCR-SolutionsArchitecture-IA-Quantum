# Cinematic timing — user approved pacing
The 3-second visual counter is independent of measured boot tasks, not a network percentage. It begins only with a visible background, advances 0–100 one integer per committed update at nominal 30ms intervals, and holds at 99 until all real resources are ready. 100% holds for 180ms before activation. A small cyan bar follows the same value inside the original energy core. The mechanical sequence is 3000ms, using an aligned reference-to-sprites handoff and symmetrical ease-in-out travel. No redraw or asset replacement. Reduced motion skips the decorative delay; failure, skip, session and route cleanup remain unchanged. Under heavy load there is no catch-up jump; total duration can exceed 6s. Tests record every DOM value, bar ratio, 99 gate, 100 hold, leaf movement, desktop/mobile timing and original particles.
